# API Endpoints

The FastAPI application provides a RESTful interface for managing documents and interacting with the AI.

## Document Management

### `GET /documents`
Retrieves a list of all uploaded documents.
- **Returns**: `List[DocumentResponse]`
- **Sorting**: Newest first.

### `POST /documents`
Uploads a new PDF document, triggering the synchronous RAG ingestion pipeline (extraction, chunking, embedding, DB persistence).
- **Body**: `multipart/form-data` containing the file.
- **Returns**: `DocumentResponse` with metadata.

### `GET /documents/{document_id}`
Retrieves metadata for a specific document.
- **Returns**: `DocumentResponse` or `404 Not Found`.

### `DELETE /documents/{document_id}`
Deletes a document and its associated chunks from the PostgreSQL database (cascade delete is configured on the ORM models).
- **Returns**: `204 No Content` or `404 Not Found`.

## Intelligence Endpoints

### `POST /search`
Performs a pure semantic search over the vectorized chunks without LLM intervention.
- **Body**: `QueryRequest` (`{ "query": "string", "limit": 5 }`)
- **Returns**: `QueryResponse` containing the top matching `ChunkResult`s.

### `POST /chat`
The standard RAG interaction endpoint. It performs semantic search and streams the LLM response generated by Google Gemini back to the client.
- **Body**: `QueryRequest`
- **Returns**: `text/plain` stream (streaming tokens).

### `POST /agent`
The LangChain ReAct agent endpoint. The LLM decides autonomously whether to search documents, count documents, or fetch document info based on the prompt intent.
- **Body**: `QueryRequest`
- **Returns**: `QueryResponse` containing the final `answer` from the agent.
